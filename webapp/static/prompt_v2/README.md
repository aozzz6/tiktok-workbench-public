## 与旧页的差异

- 结构从「三段纵向表单 + 结果区」改成 **左侧三步输入列 + 右侧结果主区 + 底部历史/导出**，生成过程中左侧可继续改，右侧保留上次结果并标「输入已修改」。
- ①②③ 始终同时可见（不是向导），改完直接点生成；③ 实时显示「15 秒 → 1 段 × 15 秒」与段数条。
- 六版默认只露标题/差异/四轴/一句口播，两段提示词折叠；点卡片开抽屉看全文与逐镜时间轴。
- 自检矩阵 6 版 × 6 项规则常驻，格子可悬停看原因，右上「逐项原因」开抽屉。
