# 「进入表格」功能说明（2026-10-19）

> 目标：把台账 sheet 从「只能在弹窗里瞥一眼」升级为**可跳转、可收藏、可返回的全屏表格视图**。
> 范围：只读查看（不提供任何写操作）；数据仍走既有 `/api/ledger/*`，不新增写接口。

---

## 1. 功能范围

| 项 | 定义 |
|---|---|
| 从哪进 | ① 账号管理列表行「表格」 ② 台账弹窗头部「进入表格」 ③ 直接访问深链 |
| 进入后展示 | 该 sheet 的**全部可见列**（按 Excel 隐藏列设置过滤）+ 行内容 + 表头排序 + 搜索 + 加载更多 |
| 携带上下文 | `file`（xlsx 文件名）、`sheet`（sheet 名）、`account`（来源账号）、`q`（定位关键词，默认 `@账号`） |
| 数据加载 | `GET /api/ledger/sheet?name=&file=&limit=200&offset=0`，超出按「加载更多」翻页 |
| 权限 | 只读视图；同源 + 本机访问（写/拉起 Excel 的接口仅回环可用） |
| 返回 | 「← 返回」回到来源视图（账号管理 / 总览 / 对标），并恢复导航高亮；也可用浏览器后退 |
| 明确不做 | 单元格编辑、新增/删除行、导出 CSV、跨表联合视图 |

---

## 2. 入口与触发

| # | 位置 | 触发 | 前置行为 |
|---|---|---|---|
| 1 | 账号管理 → 行操作「表格」 | 点击 | 先 `GET /api/ledger/resolve?account=<name>` 解析出 sheet/file；无 sheet 时 toast「该账号暂无台账 sheet」，不跳转 |
| 2 | **台账弹窗 → 表格工具栏右侧「进入表格 ↗」** | 点击 | 直接用当前表格的 file/sheet 切换；先关弹窗再进入视图（`openSheetViewFromSheet`） |
| 3 | 台账弹窗头部「进入表格」 | 点击 | 复用弹窗已有 `{file, sheet}` 上下文，关闭弹窗后跳转 |
| 4 | 地址栏深链 | 直接打开 `#sheet?file=...&sheet=...` | 页面初始化即渲染；缺失 `sheet` 时忽略路由，停在默认视图 |

> 工具栏按钮在**任何**渲染了 sheet 的地方都出现（弹窗预览等），唯独表格视图自身不显示，避免"进入表格里再进入表格"的自我循环。
> 头部按钮只在有 sheet 上下文（`openModal` 第三参）时出现。

---

## 3. 路由与参数（与现有导航风格一致）

现有导航用 `href="#view"` + `preventDefault()` 做视图切换，**不消费 hash**。
本功能在此之上只增加一条自有前缀，不改变原有导航行为：

```
#sheet?file=<xlsx 文件名>&sheet=<sheet 名>&account=<账号>&q=<定位词>
```

| 参数 | 必填 | 说明 |
|---|---|---|
| `sheet` | ✅ | sheet 名（缺失则不渲染，回落来源视图） |
| `file` | ✕ | xlsx 文件名；缺省走主台账（`tiktok_对标.xlsx`），图文簿必须带 |
| `account` | ✕ | 来源账号，仅用于标题/副标题展示 |
| `q` | ✕ | 初始搜索词；从账号卡片进入时默认 `@账号`，用于把该账号的行筛出来 |

- `openSheetView()` 写 `location.hash`，由 `hashchange` 统一渲染 → 前进/后退天然可用；
- 相同 hash 再次打开时直接重渲染（不发 hashchange）；
- 浏览器后退到无 `#sheet` 的地址时，自动切回来源视图。

---

## 4. 交互流程

```
[账号管理行] --点击表格--> resolve(account)
        ├─ 无 sheet → toast，停留原页
        └─ 有 sheet → openSheetView({file,sheet,account,q:'@account'})
                              ↓
                    location.hash = #sheet?...
                              ↓
                    activateView('sheet') + 标题/副标题/「只读」标识
                              ↓
               渲染中：host = 「加载中…」（aria-live=polite）
                              ↓
        ┌──────────── 成功 ────────────┬──── 失败 ────┬──── 0 行 ────┐
        │ 表头 + 行 + 搜索 + 加载更多   │ 错误文案      │ 表头 + 空态块 │
        │ 应用 q 过滤（未命中→退回全表）│ 重试 / 返回   │ 提示去跑采集  │
        └──────────────────────────────┴───────────────┴──────────────┘
                              ↓
           「← 返回」→ history.back() / 回退来源视图
```

状态细节：

| 状态 | 表现 | 可执行操作 |
|---|---|---|
| 加载中 | 居中「加载中…」，容器 `aria-live="polite"` | 返回 |
| 成功有数据 | 表头可点排序、搜索框过滤、底部「加载更多（已加载 n / 总 m 行）」 | 排序 / 搜索 / 加载更多 / 刷新 / Excel / 返回 |
| 成功但 0 行 | 表头 + 「这张表还没有数据」空态块 | 刷新 / 返回 |
| 失败 | 「表格加载失败」+ 后端 `detail` 原文 + 重试 / 返回 | 重试 |
| 上下文未命中 | 清空过滤、显示全表，并 toast「未找到 @xxx 的行，已显示全表」 | 继续使用 |
| 直链缺 sheet | 不切视图，停留当前页 | — |

## 5. 涉及页面与数据结构

**页面（`static/index.html`）**

- `#view-sheet`：页头（返回 / 标题 / 副标题 / 行数·只读 / Excel / 刷新）+ `#sheet-host` 容器；
- 复用 `.view` 显示机制，不新增导航项，因此不改变侧栏结构。

**前端（`static/app.js`）**

| 符号 | 作用 |
|---|---|
| `sheetViewCtx` | `{file, sheet, account, q}` 当前上下文 |
| `sheetReturnView` | 来源视图名，用于返回 |
| `openSheetView(ctx)` | 写 hash + 交给路由 |
| `renderSheetView(ctx)` | 加载并渲染，处理 loading/empty/error |
| `openAccountSheet(name, q)` | 账号 → resolve → 跳转 |
| `parseSheetHash()` / `sheetHashOf()` | 路由编解码 |
| `showReturnView(name)` | 切回来源视图并恢复导航高亮 |

**接口（`app.py`，均为既有接口）**

| 接口 | 用途 | 关键返回 |
|---|---|---|
| `GET /api/ledger/resolve?account=` | 账号 → sheet | `{sheet, file, candidates}` |
| `GET /api/ledger/sheet?name=&file=&limit=&offset=` | 表数据 | `{header[], rows[][], total, hidden_cols[], checks[]}` |
| `POST /api/ledger/open {file,sheet}` | 本机 Excel 打开 | `{ok}` |

**表头**：来自 xlsx 第一行（去掉 Excel 隐藏列），因此列集合随台账版本变化，前端不写死；
当前 14 列主线为：记录日期 / @账号 / 发布时间 / 标题 / 文案 / 链接（含 ID）/ 出单量 / 播放·点赞·评论·转发·收藏 / 音频 / 翻译 / 风格标签。

## 6. 权限校验

| 层 | 措施 |
|---|---|
| 视图 | 纯只读：无输入框写回、无保存按钮；所有数据来自 GET |
| 接口 | `POST /api/ledger/open` 新增 `_guard_local_write`：仅接受 127.0.0.1 / ::1 / localhost，其他来源 403 |
| 数据 | sheet 与 file 均经服务端白名单解析（`_ledger_file`），不接受任意路径 |
| 越权风险 | 无写接口可被本视图触发；Excel 拉起的进程只在本机 |

---

## 7. 返回路径

1. 页头「← 返回」：优先 `history.back()`（退掉 hash 历史），80ms 内若仍停在表格视图则兜底 `showReturnView(来源)`；
2. 浏览器后退：`hashchange` 发现不是 `#sheet`，切回来源视图；
3. 来源视图会恢复侧栏高亮，并按需刷新数据（accounts / overview / bench）。

## 9. 已知边界

- 搜索/排序只作用于**已加载窗口**（首屏 200 行），底部会明确提示"仅作用于已加载的 N / M 行"；
  需要全表搜索时用「加载更多」或直接用 Excel。
- 深链只带文件名不带绝对路径；文件被移动/改名后需重新从入口进入。
- 表格视图与弹窗共用同一份 `sheetState`：先开弹窗再进视图会以后者为准（弹窗关闭后清空）。已通过"进入表格后重新加载"规避。
