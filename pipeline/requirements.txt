# 下面那行 --extra-index-url 是为 torch 准备的：torch==2.7.0+cpu 是 CPU 轮子，
# PyPI 上没有这个版本（PyPI 的 2.7.0 是 CUDA 版，体积大得多），它只在 PyTorch 自己的
# CPU 索引里。这里用 --extra-index-url 而不是 --index-url：PyPI 仍是主索引，
# 其余 6 个包照常从 PyPI 装，不会全被指到 PyTorch 索引去。
# 本机实测：torch.__version__ == 2.7.0+cpu，torch.cuda.is_available() == False。
#
# 不在本清单里的两个（有意不列，因为 pipeline\.venv 里没有它们）：
#   - scrapling：抓取层的可选首选实现，没有时 tiktok_fetch.py 自动退回 curl_cffi。
#   - playwright：只有浏览器兜底（pw_detail_fallback.py / pw_uid_fallback.py）用，
#     而且必须装在系统 Python 里，不是这个 venv。
