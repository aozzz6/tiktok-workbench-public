# TikTok 对标工作台 · 绿色版 使用说明

这套工具**不用安装、不用管理员密码**：解压出来，双击一个文件就能用。
所有东西（程序、模型、你的台账和历史）都在你解压出来的那个文件夹里，拷走就能用。

三步上手：

1. **解除锁定**——从网上下载的压缩包，先做第一节那一步。
2. **解压**——解压到一个你自己的文件夹（第二节）。
3. **启动**——双击 `启动工作台.bat`，浏览器会自己打开工作台页面（第三节）。

后面按你会遇到事情的顺序写：首次使用（第四节）、更新（第五节）、备份（第六节）、
常见故障（第七节）、版本与日志（第八节）。

> ⚠ 有 3 件事现在**还做不到**，先看第四节里的「现在还不能做的三件事」，免得白折腾。

---

## 一、解除锁定（下载完先做这一步）

Windows 对"从网上下载"的文件会加一个锁。不解锁，里面的程序可能被杀掉或打不开。

1. 找到你下载的那个压缩包（`.zip`），**先不要解压**。
2. 鼠标**右键**点它，选最下面的「属性」。
3. 在弹出的窗口最下面，找一行写着「安全：此文件来自其他计算机，可能被阻止…」。
4. 勾上旁边的「解除锁定」，点「确定」。
5. 如果属性里**没有**这一行，说明不用解锁，直接去第二节。

> 这一步只做一次，做完再解压。解压出来的文件夹不需要再解锁。

---

## 二、解压

1. 右键点那个压缩包，选「全部解压缩…」。
2. 目标文件夹填一个你自己的位置，例如 D:\工作台。
   - 建议放在 D 盘根目录下一层，**路径越简单越好**。
   - 中文、空格一般可以，但极少数情况下会出问题；遇到怪问题先换到纯英文路径试试（见第七节）。
3. 点「解压」，等它走完。
4. 打开解压出来的文件夹，你应该看到这些：
   - 几个 bat 文件：`启动工作台.bat`、`检查环境.bat`、`重启工作台.bat`
   - 一些文件夹：`python\`、`webapp\`、`pipeline\`、`ledger\`、`models\`、`logs\`、`workbuddy\`
   - 一个 `VERSION` 文件（里面是版本号）
   - 本文件 `使用说明.md`

> **不要**在压缩包里直接双击 `启动工作台.bat`。
> 那样 Windows 会把它解压到一个临时目录，你改的东西下次就没了。

## 三、启动

1. 双击 `启动工作台.bat`。
2. 会弹出一个黑色的窗口，里面滚几行字，然后**它自己会关掉**——这是正常的，
   工作台已经在后台跑起来了。
3. 浏览器会自动打开一个地址，通常是 http://127.0.0.1:8789/ ，看到工作台页面就成功了。
4. 如果你双击后黑窗口**没有**自己关掉，而是停在那里并显示 `[ERROR]`，
   说明启动失败：照着第七节的第 2 条做。

**关于端口（地址最后那个数字）**

- 8789 是默认端口。如果这个端口已经被别的程序占了，启动器会自动往下换：
  先试 8791，再试 8792，再试 8793。
- 换到哪个，黑窗口里就会打印那个地址，浏览器打开的也一定是它——
  **你不用记，看浏览器地址栏就行**（例如 127.0.0.1:8792）。
- 已经有一个工作台在跑的时候，双击 `启动工作台.bat` 会直接复用那个页面，不会开第二个。

**重启**

- 双击 `重启工作台.bat` 就是重启（会先结束旧的，再在同一端口起新的）。
- 页面打不开、或者改了设置要生效，双击它一次就行。

**关掉**

- 关掉浏览器标签页**不会**停止工作台，它在后台继续跑（定时日更需要它开着）。
- 想彻底关掉：重启电脑即可；或者用任务管理器（Ctrl+Shift+Esc）结束名字叫 Python 的进程。
  日常不建议关，关了就收不到定时日更。

## 四、首次使用

### 现在还不能做的三件事（重要）

**① 反推页面不能粘贴 TikTok 链接自动下载。**
包里其实**带**了下载工具 yt-dlp，但工作台只认 `WB_YTDLP` 这一个设置（默认值是开发机的路径），
所以**现在**粘贴链接不会下载。要用反推/对标，请自己先把视频下到本地（手机上、浏览器里存下来都行），
再用页面上的「本地视频」导入。
（采集 TikTok 需要代理，见下面第 ③ 条。）

**② AI 翻译、AI 对话必须联网，而且要你自己填 API key。**
AI 功能是调用云端大模型的，所以：联网 + 一个你自己的 API key，缺一不可。
key 要填在 `workbuddy\models.json` 这个文件里（这个文件第一次用 AI 功能时才出现；
包里**不带**任何 key，也不该带）。没网或没 key 时，AI 翻译/对话会直接报错，这是正常的。

**③ 采集 TikTok 要自己的代理；反推和 AI 功能要联网。**
- **离线可用**：看台账、对标分析、转写（完整包连转写模型都随包带着）。
- **需要联网**：AI 翻译、AI 对话、反推。反推要调用远程的「视觉模型」看画面，
  所以它**不能**离线；这三样都要你自己填 API key（见第 ② 条）。
- 采集 TikTok 要一个能连上 TikTok 的网络代理，在账号设置里填好自己的代理地址。

### 第一步：检查环境（可选，但建议做一次）

1. 双击 `检查环境.bat`。
2. 它会列出三行：包内解释器、ffmpeg、模型；最后一行是结果。
3. 看到 `[OK]` 或 `[WARN]` 都没关系（`[WARN]` 只是提醒，例如模型要等第一次转写才下载）。
   看到 `[FAIL]` 才是真有问题，把窗口内容截图，按第七节处理。
4. 窗口会停住，按任意键关闭。

### 第二步：加一个对标账号

1. 页面上方找到「账号管理」（或「一键运行」页面里的「＋ 新增对标账号」）。
2. 填**账号名**（就是 TikTok 上那个 @ 后面的名字，必填）、面向地区、语种。
3. 保存。加错了可以删掉重加，不影响别的账号。

### 第三步：跑一次

1. 进「一键运行」页面。
2. 选账号、选开始日期和结束日期（同一天就两个都选那天）。
3. 「转写语言」选「自动（账号语言）」就行。
4. 「转写后端」保持 `auto`，**不要改**（没有显卡的电脑会自动用更适合的方式跑）。
5. 点「开始运行」，下面的「运行进度」会滚动显示每一步。
6. 跑完看「运行记录」，绿色的就是成功。

### 关于转写（把视频里的话变成文字）

- **完整包**（文件大的那个）：模型已经随包带来，**断网也能转**。
- **精简包**（文件小的那个）：第一次转写要联网下载模型，约 1.5 GB，
  黑窗口里会显示「正在下载…约 1.5 GB」；下一次就不用再下了。
- 转写只用本机处理器（不需要显卡），一段 45 秒的英文音频大约 20~30 秒出结果（机器快慢会有差别）。

## 五、更新（换成新版本，数据不丢）

升级**不是**删掉重装。你的台账、账号、历史、模型都在旧文件夹里，要保留。

1. 下载新版本的压缩包 → 按第一节**解除锁定**。
2. 解压到**另一个**空文件夹，例如 D:\工作台-新版（不要解压到旧文件夹里面）。
3. 打开新文件夹，全选里面所有内容（Ctrl+A），复制（Ctrl+C）。
4. 回到**旧**文件夹，粘贴（Ctrl+V）。
5. 出现「目标中已有同名文件」的提示时，选「**替换目标中的文件**」。
6. 双击 `重启工作台.bat`，让新版本生效。

**粘贴替换时，下面这些东西是你的数据，绝对不要删**（第 3 步复制的是程序，不是它们）：

- `ledger\` —— 台账（Excel）
- `pipeline\output\` —— 抓到的视频、转写文本、中间产物
- `models\` —— 转写模型（完整包才带；删了要重新下载 1.5 GB）
- `webapp\data\` —— 页面自己的数据
- `workbuddy\` —— 你的账号、AI key、设置
- `_setenv.local.bat` —— 你自己加的本地设置（如果你有的话；没有就不用管）

> 记不住也没关系：**复制粘贴不会删掉它们**，只有你手动删才会没。
> 所以升级完最忌讳的操作是「把旧文件夹整个删掉，再把新的改名」。

## 六、备份

备份就是「复制一份放着」，没有任何专门的操作。

**全量备份（推荐，简单）**

1. 把整个工作台文件夹复制到别的地方（U 盘、另一个硬盘、网盘）。
2. 或者右键文件夹 →「压缩为 ZIP」，得到一个压缩包放着。
3. 建议每周一次，或者每次大改之前一次。

**只备份数据（文件小）**

只把下面这几个文件夹复制出来就够了（程序可以随时重新下载）：

- `ledger\`
- `pipeline\output\`
- `workbuddy\`
- `webapp\data\`
- `VERSION`（记一下版本号，恢复时对得上）

**换电脑 / 换目录**

把整个文件夹拷到新电脑（或 U 盘），直接双击 `启动工作台.bat` 就能用，
不需要在新电脑上装任何东西，台账和历史都跟着走。

> 注意：新电脑第一次启动时，Windows 可能弹出防火墙提示，选「允许」即可（只监听本机，不对外）。

## 七、常见故障

按「你看到什么」找对应的一条。

**1. 杀毒软件/Windows 安全中心把 python.exe 拦了或删了**

- 现象：启动失败、黑窗口里报找不到文件；或者安全软件弹出「已阻止」。
- 处理：把整个工作台文件夹加入杀毒软件的「信任 / 排除」列表，
  再去「保护历史记录 / 隔离区」把被删的文件**还原**；如果文件已经被删掉，
  重新解压一次压缩包（数据文件夹别覆盖）。

**2. 双击后黑窗口一闪就没、或者报错**

- 先双击 `检查环境.bat`，看有没有 `[FAIL]` 那几行，红字就是原因。
- 再看日志：打开 `logs\` 文件夹，用记事本打开 `logs\_server_run.log`，翻到最下面几行。
- 黑窗口停住并显示 `[ERROR] workbench did not start` 时，日志里一定有更具体的原因。

**3. 端口被占用（页面打不开，或者用了别的端口）**

- 8789 被占了不要紧，启动器会自动换到 8791 / 8792 / 8793。
- 看浏览器地址栏的数字，或者黑窗口里「就绪：http://127.0.0.1:xxxx/」那一行。
- 想让 8789 空出来：关掉占用它的其它程序，再双击 `重启工作台.bat`。

**4. 模型下载失败（精简包第一次转写时）**

- 现象：黑窗口里写「正在下载…约 1.5 GB」然后报错、或者一直不动。
- 原因：下模型要联网，国内网络经常连不上 HuggingFace。
- 处理：在文件夹里新建一个文本文件，输入下面这一行：

  `set HF_ENDPOINT=https://hf-mirror.com`

  保存时文件名写成 `_setenv.local.bat`（保存类型选「所有文件」，不要存成 .txt），
  然后双击 `重启工作台.bat` 再试。
- 还是不行就检查：磁盘空间够不够（要留 2 GB 以上）、能不能正常打开网页。

**5. 缺少 VC 运行库（报 0xc000007b 或者找不到 msvcp140.dll）**

- 现象：一启动就弹「无法启动此程序，因为计算机中丢失 …」或错误码 0xc000007b。
- 包里 `python\` 文件夹已经自带这些运行库文件（例如 `python\msvcp140.dll`），
  通常是杀软把它们删了：按第 1 条把它们还原，或者重新解压一次（只解压 python 文件夹）。
- 仍然报错：装一个「Microsoft Visual C++ 2015-2022 可再发行组件（x64）」，
  下载地址在微软官网，装完重启电脑再双击启动。

**6. 中文或空格路径引起怪问题**

- 现象：能启动但功能怪怪的、转写报错、或者文件读写失败。
- 处理：把整个文件夹移到**纯英文、无空格**的路径，例如 D:\wb，
  然后双击 `启动工作台.bat`。数据都在文件夹里，移过去不会丢。

**7. 浏览器没自动打开**

- 不要急，先看黑窗口里那行「就绪：http://127.0.0.1:xxxx/」，把地址手动粘到浏览器地址栏。
- 也可以直接打开 http://127.0.0.1:8789/ 试试；换过端口的就从 8791、8792、8793 里找。
- 页面空白就按 F5 刷新一次，或者等 3~5 秒（第一次启动要初始化）。

## 八、版本与日志

**看版本号**

- 用记事本打开根目录的 `VERSION` 文件，里面那一行（例如 `0.1.0`）就是版本号。
- 想确认包有没有解压完整：根目录同时应该有 `VERSION` 和 `build-info.json`。

**看日志**

- 工作台的运行日志在 `logs\_server_run.log`，用记事本打开，看**最后 20~50 行**就有线索。
- `logs\` 里如果还有别的 log 文件，按时间最新的那个看。
- `检查环境.bat` 的输出也有用：把那个黑窗口的内容截图或复制下来。

**反馈问题时请一起给这三样**

1. 版本号（`VERSION` 里的那一行）
2. `检查环境.bat` 的完整输出（截图即可）
3. `logs\_server_run.log` 的最后 20~50 行

有这三样，绝大多数问题看一眼就能定位，不用来回问。

## 附录：这个包的目录里都是什么（看得懂就够了，不用动）

- `启动工作台.bat` —— 日常就双击它
- `检查环境.bat` —— 出问题时双击它，看缺什么
- `重启工作台.bat` —— 重启（改了设置、页面打不开时用）
- `_setenv.bat` —— 启动时自动读的"小本子"，别改
- `python\` —— 随包带的 Python，双击它没用，别动
- `webapp\` —— 页面程序；`webapp\data\` 是页面数据
- `pipeline\` —— 采集、转写、反推的脚本；`pipeline\output\` 是跑出来的东西
- `ledger\` —— 台账 Excel 存这里
- `models\` —— 转写模型（完整包才带）
- `logs\` —— 日志
- `workbuddy\` —— 账号、AI key、设置
- `ffmpeg\` —— 音视频工具，随包带
- `licenses\` —— 第三方软件的许可证（不用看）
- `VERSION` —— 版本号
- `使用说明.md` —— 就是本文件
